# vmux

Native macOS AI dev cockpit — an "AI terminal observatory". Run autonomous AI agents (Claude Code, …) in PTY terminals; vmux acts as an MCP proxy routing tool calls to external MCP servers (primarily Chrome DevTools MCP for browser autonomy), observes everything via an Activity stream + Session Replay timeline, gates dangerous ops via an Approval queue, and reviews agent file edits inline via diff review.

No embedded browser. No built-in editor — jump to your existing editor (VS Code/Cursor/Neovim/JetBrains) for actual editing.

## Architecture

```
vmux/
├── app/                      # Swift app (SwiftUI + AppKit), project generated by XcodeGen
│   ├── project.yml           # XcodeGen spec (source of truth for the Xcode project)
│   └── Vmux/                 # Swift sources
├── sidecar/                  # Go sidecar (JSON-RPC over Unix socket, PTY, MCP proxy)
│   ├── go.mod
│   ├── cmd/vmux-sidecar/     # main entrypoint
│   └── internal/             # internal packages
├── shared/                   # JSON-RPC schemas, MCP tool specs (shared contract)
├── scripts/                  # build/dev/dmg scripts
└── Makefile
```

The Go sidecar is embedded in `Vmux.app/Contents/Resources/vmux-sidecar`. The app launches it on first window open and terminates it on quit; the sidecar also self-terminates if its parent process dies (no orphans).

## Requirements

- macOS 14.0+ (Sonoma)
- Xcode 16+ (Swift 6)
- Go 1.23+
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) — `brew install xcodegen`
- [create-dmg](https://github.com/create-dmg/create-dmg) — `brew install create-dmg` (only for `make dmg`)

## Build

```bash
make deps        # generate Xcode project from project.yml (XcodeGen)
make build       # build universal sidecar + app (Debug, unsigned)
make dev         # run app + sidecar in dev mode
make test        # run Go + Swift tests
make dmg         # signed + notarized DMG (requires Developer ID env vars, see below)
make clean       # remove build artifacts
```

### Developer ID setup (for `make dmg`)

Set these environment variables (e.g. in CI secrets or a local untracked `.env`):

```bash
export VMUX_SIGN_IDENTITY="Developer ID Application: Your Name (TEAMID)"
export VMUX_TEAM_ID="TEAMID"
export VMUX_NOTARY_PROFILE="vmux-notary"   # a `xcrun notarytool store-credentials` keychain profile
```

Notarization runs only on the release CI job, not on every PR.
