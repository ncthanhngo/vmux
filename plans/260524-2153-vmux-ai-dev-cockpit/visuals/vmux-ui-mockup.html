myapp

A JWT-authenticated REST API for user management. Built with Fastify + TypeScript.

Quickstart

# install
npm install

# dev server
npm run dev # → localhost:3000

Auth flow

The auth middleware verifies JWTs on protected routes:

  • POST /auth/login — exchange credentials for token
  • GET /api/users/me — requires Authorization: Bearer
Note · JWT secret must be ≥ 32 chars. See .env.example.
