# Phase 1: Project setup & build pipeline

## Overview

Bootstrap repo: Swift app skeleton + Go sidecar skeleton + shared build script that produces a single signed DMG with the Go binary embedded as a Helper. Establish CI for both sides. No business logic yet — goal is "`make dmg` produces an installable app that launches an empty window and a sidecar process".

## Requirements

- Functional: `make dev` runs Swift app + Go sidecar in dev mode; `make dmg` produces a notarized DMG.
- Non-functional: cold build < 60s, incremental < 5s. Reproducible. CI-runnable on macOS runners.

## Architecture

```
vmux/
├── app/                      # Swift app (Xcode project)
│   ├── Vmux.xcodeproj
│   └── Vmux/                 # SwiftUI + AppKit sources
├── sidecar/                  # Go module
│   ├── go.mod
│   ├── cmd/vmux-sidecar/
│   └── internal/
├── shared/                   # JSON-RPC schemas, MCP tool specs (shared truth)
├── scripts/
│   ├── build-sidecar.sh      # cross-compile arm64+x86_64, lipo into universal
│   ├── build-app.sh          # xcodebuild archive
│   ├── make-dmg.sh           # codesign + create-dmg + notarytool
│   └── dev.sh                # spawn both for local dev
├── Makefile
└── .github/workflows/ci.yml
```

Sidecar is embedded in `Vmux.app/Contents/Resources/vmux-sidecar`. Swift launches it on first window open and terminates it on quit.

## Implementation Steps

1. Init git repo + `.gitignore` (Swift, Go, macOS, Xcode patterns).
2. Create Swift app via Xcode: SwiftUI lifecycle, **deployment target macOS 14.0+ (Sonoma)**, App Sandbox **off**, Hardened Runtime **on**. <!-- Updated: Validation Session 1 - macOS target raised to 14.0+ -->`
3. Create Go module `sidecar/`; `main.go` prints "vmux-sidecar v0.0.0" + listens on `~/Library/Application Support/vmux/sidecar.sock`.
4. `scripts/build-sidecar.sh`: `GOOS=darwin GOARCH=arm64`, `GOOS=darwin GOARCH=amd64`, `lipo -create -output vmux-sidecar`.
5. Xcode Run Script phase: copy sidecar binary into `Contents/Resources/`. `chmod +x`.
6. Swift app on launch: locate sidecar via `Bundle.main.url(forResource:)`, `Process.run()`, log stdout/stderr to `~/Library/Logs/vmux/sidecar.log`.
7. `scripts/make-dmg.sh`: `xcodebuild archive` → export → `codesign --deep --options runtime` → `create-dmg` → `xcrun notarytool submit --wait` → `staple`.
8. Makefile targets: `dev`, `build`, `dmg`, `clean`, `test`.
9. CI: macOS-latest runner. Steps: setup Go, setup Xcode, `make test`, `make build` (skip notarize on PR).
10. README with build instructions + Developer ID setup notes.

## Risk Assessment

- **Notarization flakiness**: Apple notary service can be slow/intermittent. Mitigation: notarize only on release CI job, not every PR.
- **Sidecar zombie processes**: if Swift crashes, sidecar orphaned. Mitigation: sidecar polls parent PID, exits when parent dies.
- **Code signing of embedded binary**: nested binary must be signed before outer. Mitigation: explicit signing order in `make-dmg.sh`.

## Security Considerations

- Hardened Runtime enabled; entitlements minimal (no JIT, no library validation disabled — yet).
- Unix socket permissions `0600` (user-only).
- No secrets in repo; Developer ID via env vars on CI.
